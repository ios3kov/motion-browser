# Motion Browser

**Found it → Send to AE → work.**

Motion Browser is a web-to-After-Effects tool for sending selected media, text, colors, references and supported web motion directly into an AE project, preserving editability where it is realistically supported.

## Status

Early product definition and technical feasibility research.

- Product discovery: `docs/PRODUCT_DISCOVERY.md`
- Project status: `docs/STATUS.md`
- Requirement traceability: `docs/REQUIREMENT_TRACEABILITY.md`
- First technical spike: `docs/TECH-001-BROWSER-FEASIBILITY.md`
- Engineering standard: [AE-Development-Rules](https://github.com/ios3kov/AE-Development-Rules), baseline v8.0.0

No production architecture has been selected yet. The first gate is proving the supported browser-to-AE path in the actual After Effects runtime.
